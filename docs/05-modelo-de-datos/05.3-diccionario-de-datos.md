# 05.3 Diccionario de Datos Completo

## 1. Catálogos Cerrados (10 Tipos `Enum` en PostgreSQL)

| Enum | Valores permitidos | Uso y significado |
| :--- | :--- | :--- |
| `PromptStatus` | `DRAFT`, `ACTIVE`, `ARCHIVED` | Estado de una versión del Prompt Padre: Borrador, Vigente (máximo 1 por proyecto) o Histórica. |
| `ContractStatus` | `DRAFT`, `APPROVED`, `DEPRECATED` | Estado de un contrato: Borrador, Aprobado/Congelado (máximo 1 por proyecto+módulo) o Desactualizado/Retirado. |
| `SyncStatus` | `PENDING`, `SYNCED`, `FAILED`, `CONFLICT` | Estado de sincronización de un archivo contra GitHub (`CONFLICT` = cambio manual detectado por SHA). |
| `HttpMethod` | `GET`, `POST`, `PUT`, `PATCH`, `DELETE` | Método HTTP oficial del endpoint definido en el contrato. |
| `AiProvider` | `GEMINI`, `OPENAI`, `DEEPSEEK` | Proveedores de IA soportados en la bóveda de claves del MVP. |
| `AuditRefType` | `BRANCH`, `PR` | Modalidad de referencia auditada en GitHub: rama comparada contra `defaultBranch`, o Pull Request contra su rama base. |
| `AuditLayer` | `FRONTEND`, `BACKEND`, `BOTH` | Capa seleccionada por el usuario al disparar "Auditar ahora". |
| `FindingLayer` | `FRONTEND`, `BACKEND`, `BOUNDARY` | Capa origen de un hallazgo (`BOUNDARY` = invasión mecánica de carpetas). |
| `TrafficLight` | `GREEN`, `YELLOW`, `RED`, `ERROR` | Veredicto visual de la auditoría (`ERROR` = fallo técnico sin violación previa de frontera). |
| `Severity` | `CRITICAL`, `HIGH`, `MEDIUM`, `LOW` | Nivel de gravedad de un hallazgo individual. |

## 2. Diccionario de Tablas — Etapa 1A (Base Organizadora)

### Tabla 1: `User` (Usuarios)
Almacena la identidad proveniente de GitHub OAuth, el control de revocación de sesiones y el token cifrado de GitHub.

| Campo | Tipo Prisma (PostgreSQL) | Nulo | Restricción | Por defecto | Descripción funcional y ejemplo |
| :--- | :--- | :--- | :--- | :--- | :--- |
| `id` | `String` (`TEXT`) | No | `PK` | `cuid()` | Identificador interno único. |
| `githubId` | `String` (`TEXT`) | No | `UK` | — | ID numérico de GitHub en texto. Ej: `"8492014"` |
| `username` | `String` (`TEXT`) | No | — | — | Usuario público de GitHub. |
| `email` | `String` (`TEXT`) | Sí | — | `null` | Correo de GitHub (opcional si es privado). |
| `avatarUrl` | `String` (`TEXT`) | Sí | — | `null` | URL del avatar de GitHub. |
| `sessionVersion` | `Int` (`INTEGER`) | No | — | `1` | Contador incrementado al cerrar sesión para revocar tokens previos de inmediato. |
| `keyVersion` | `Int` (`INTEGER`) | No | — | `1` | Versión de la llave maestra usada para cifrar el token de GitHub. |
| `githubTokenEncrypted` | `String` (`TEXT`) | No | — | — | Token OAuth cifrado con AES-256-GCM en formato `base64` (`AAD = userId`). |
| `githubTokenIv` | `String` (`TEXT`) | No | — | — | Vector de inicialización de 12 bytes en `base64`. |
| `githubTokenTag` | `String` (`TEXT`) | No | — | — | Etiqueta de autenticidad de 16 bytes en `base64`. |
| `createdAt` | `DateTime` (`TIMESTAMP`) | No | — | `now()` | Fecha de registro en UTC. |
| `updatedAt` | `DateTime` (`TIMESTAMP`) | No | — | auto | Última actualización. |

### Tabla 2: `Project` (Proyectos Conectados)
Representa un repositorio de GitHub vinculado, sus rutas normalizadas y el estado de sincronización de `agents.md`.

| Campo | Tipo Prisma (PostgreSQL) | Nulo | Restricción | Por defecto | Descripción funcional y ejemplo |
| :--- | :--- | :--- | :--- | :--- | :--- |
| `id` | `String` (`TEXT`) | No | `PK` | `cuid()` | Identificador único del proyecto. |
| `userId` | `String` (`TEXT`) | No | `FK → User.id` | — | Usuario propietario. |
| `githubRepoId` | `String` (`TEXT`) | No | `UK compuesta` | — | ID inmutable del repositorio en GitHub (resiste cambios de nombre). |
| `name` | `String` (`TEXT`) | No | — | — | Nombre legible asignado en la plataforma (3 a 80 caracteres). |
| `repoOwner` | `String` (`TEXT`) | No | — | — | Dueño del repo normalizado en minúsculas. |
| `repoName` | `String` (`TEXT`) | No | — | — | Nombre del repo normalizado en minúsculas. |
| `defaultBranch` | `String` (`TEXT`) | No | — | `"main"` | Rama base para sincronización y comparación de ramas. |
| `contractsPath` | `String` (`TEXT`) | No | — | `"contracts"` | Ruta normalizada sin barra inicial ni final. |
| `frontendPath` | `String` (`TEXT`) | No | — | `"frontend"` | Ruta normalizada de Frontend. |
| `backendPath` | `String` (`TEXT`) | No | — | `"backend"` | Ruta normalizada de Backend. |
| `agentsMdSyncStatus` | `SyncStatus` (`ENUM`) | No | — | `PENDING` | Estado de sincronización de `agents.md` en la raíz del repositorio. |
| `agentsMdSha` | `String` (`TEXT`) | Sí | — | `null` | Último blob SHA conocido de `agents.md` en GitHub para control de conflictos. |
| `agentsMdSyncedAt` | `DateTime` (`TIMESTAMP`) | Sí | — | `null` | Fecha de la última sincronización exitosa de `agents.md`. |
| `agentsMdLastSyncError` | `String` (`TEXT`) | Sí | — | `null` | Detalle del último error o conflicto al publicar `agents.md`. |
| `createdAt` | `DateTime` (`TIMESTAMP`) | No | — | `now()` | Fecha de vinculación. |
| `updatedAt` | `DateTime` (`TIMESTAMP`) | No | — | auto | Última actualización. |

*Restricción compuesta:* `UNIQUE(userId, githubRepoId)` (cubre también búsquedas por `userId`).

### Tabla 3: `ParentPromptVersion` (Versiones del Prompt Padre)
Mantiene el historial inmutable del Prompt Padre (`v1`, `v2`, `v3`...) y el estado de publicación en `.orquestador/prompt-padre.md`.

| Campo | Tipo Prisma (PostgreSQL) | Nulo | Restricción | Por defecto | Descripción funcional y ejemplo |
| :--- | :--- | :--- | :--- | :--- | :--- |
| `id` | `String` (`TEXT`) | No | `PK` | `cuid()` | Identificador único de la versión. |
| `projectId` | `String` (`TEXT`) | No | `FK → Project.id` | — | Proyecto al que pertenece. |
| `versionNumber` | `Int` (`INTEGER`) | No | `UK compuesta` | — | Número secuencial (`1`, `2`, `3`...). |
| `summary` | `String` (`TEXT`) | Sí | — | `null` | Nota breve de cambios (máx. 280 caracteres). |
| `content` | `String` (`TEXT`) | No | — | — | Texto Markdown del Prompt Padre (máx. 50 000 caracteres). |
| `status` | `PromptStatus` (`ENUM`) | No | Índice parcial* | `DRAFT` | `DRAFT`, `ACTIVE` (máximo 1 por proyecto) o `ARCHIVED`. |
| `syncStatus` | `SyncStatus` (`ENUM`) | No | — | `PENDING` | Estado de publicación en `.orquestador/prompt-padre.md`. |
| `githubFileSha` | `String` (`TEXT`) | Sí | — | `null` | Último blob SHA de `.orquestador/prompt-padre.md` en GitHub. |
| `syncedToGithubAt` | `DateTime` (`TIMESTAMP`) | Sí | — | `null` | Fecha de sincronización exitosa con GitHub. |
| `lastSyncError` | `String` (`TEXT`) | Sí | — | `null` | Motivo del último fallo/conflicto de sincronización. |
| `createdAt` | `DateTime` (`TIMESTAMP`) | No | — | `now()` | Fecha de creación. |

*Restricciones:* `UNIQUE(projectId, versionNumber)` + índice único parcial SQL `WHERE status = 'ACTIVE'`.

### Tabla 4: `Contract` (Contratos en TypeScript)
Almacena cada contrato, su definición editable en `schemaJson`, su salida determinista `.ts` (solo lectura) y su estado de sincronización.

| Campo | Tipo Prisma (PostgreSQL) | Nulo | Restricción | Por defecto | Descripción funcional y ejemplo |
| :--- | :--- | :--- | :--- | :--- | :--- |
| `id` | `String` (`TEXT`) | No | `PK` | `cuid()` | Identificador único del contrato. |
| `projectId` | `String` (`TEXT`) | No | `FK → Project.id` | — | Proyecto al que pertenece. |
| `moduleName` | `String` (`TEXT`) | No | `UK compuesta` | — | Slug en minúsculas con guiones (`^[a-z][a-z0-9-]{1,48}$`). Ej: `"auth-login"` |
| `versionNumber` | `Int` (`INTEGER`) | No | `UK compuesta` | `1` | Número de versión de ese módulo (`1`, `2`...). |
| `status` | `ContractStatus` (`ENUM`) | No | Índice parcial* | `DRAFT` | `DRAFT`, `APPROVED` (máximo 1 por proyecto+módulo) o `DEPRECATED`. |
| `httpMethod` | `HttpMethod` (`ENUM`) | No | — | — | Verbo HTTP (`GET`, `POST`, `PUT`, `PATCH`, `DELETE`). |
| `endpointPath` | `String` (`TEXT`) | No | — | — | Ruta del endpoint. Ej: `"/api/v1/auth/login"`. |
| `schemaJson` | `Json` (`JSONB`) | No | — | — | Estructura validada por Zod (ver Subdocumento `05.6`). |
| `tsContent` | `String` (`TEXT`) | No | — | — | Código TypeScript generado determinísticamente desde `schemaJson`. |
| `filePath` | `String` (`TEXT`) | No | — | — | Ruta destino normalizada sin barra inicial. Ej: `"contracts/auth-login.contract.ts"`. |
| `generatedByAi` | `Boolean` (`BOOLEAN`) | No | — | `false` | `false` = formulario manual (1A); `true` = asistido por IA (1B). |
| `approvedAt` | `DateTime` (`TIMESTAMP`) | Sí | — | `null` | Marca de tiempo obligatoria del clic humano de aprobación. |
| `syncStatus` | `SyncStatus` (`ENUM`) | No | — | `PENDING` | Estado de publicación en GitHub. |
| `githubFileSha` | `String` (`TEXT`) | Sí | — | `null` | Último blob SHA del archivo `.ts` en GitHub. |
| `syncedToGithubAt` | `DateTime` (`TIMESTAMP`) | Sí | — | `null` | Fecha de la última publicación exitosa. |
| `lastSyncError` | `String` (`TEXT`) | Sí | — | `null` | Motivo del último fallo/conflicto. |
| `createdAt` | `DateTime` (`TIMESTAMP`) | No | — | `now()` | Fecha de creación del borrador. |
| `updatedAt` | `DateTime` (`TIMESTAMP`) | No | — | auto | Última modificación. |

*Restricciones:* `UNIQUE(projectId, moduleName, versionNumber)` + índice único parcial SQL `WHERE status = 'APPROVED'`.

### Tabla 8: `AuditFinding` (Hallazgos y Prompts de Arreglo)

| `auditRunId` | `String` (`TEXT`) | No | `FK → AuditRun.id` | — | Auditoría padre. |
| `layer` | `FindingLayer` (`ENUM`) | No | — | — | Origen: `FRONTEND`, `BACKEND` o `BOUNDARY`. |
| `severity` | `Severity` (`ENUM`) | No | — | — | Gravedad: `CRITICAL`, `HIGH`, `MEDIUM` o `LOW`. |
| `filePath` | `String` (`TEXT`) | No | — | — | Ruta normalizada sin barra inicial. Ej: `"backend/src/routes/auth.ts"`. |

| `createdAt` | `DateTime` (`TIMESTAMP`) | No | — | `now()` | Fecha de registro. |
